## 🏗️ 프로젝트 컨텍스트

**프로젝트명**: 노션 기반 견적서 웹 뷰어

**핵심 문제**:

- 현재 노션(Notion)에서 견적서를 작성하고 있으나, 클라이언트에게 공유 시 노션 계정 없이는 보기 불편함
- PDF 다운로드가 번거롭고 디자인이 일관되지 않음
- 브랜드 이미지에 맞는 견적서 양식이 없음

**솔루션**:

- 노션 API로 견적서 데이터를 가져와 웹에서 전문적으로 렌더링
- 클라이언트는 링크만으로 견적서를 확인하고 PDF로 저장 가능

## 🛠️ 기술 스택 (반드시 준수)

```
- Framework: Next.js 15.5.3 (App Router + Turbopack)
- Runtime: React 19.1.0 + TypeScript 5
- Styling: TailwindCSS v4 + shadcn/ui (new-york style)
- Forms: React Hook Form + Zod + Server Actions
- UI Components: Radix UI + Lucide Icons
- 상태관리: Zustand
- any 타입 사용 금지
- 컴포넌트 분리 및 재사용 필수
- 반응형 필수 (모바일 우선)
```

## 📌 MVP 핵심 기능 요구사항

### 기능 1: 노션 연동

- 노션 API를 통해 특정 데이터베이스에서 견적서 데이터 조회
- 견적서 ID(slug)로 개별 견적서 접근 가능
- 노션 데이터베이스 구조: 견적번호, 클라이언트명, 항목 목록, 단가, 수량, 세율, 발행일, 유효기간

### 기능 2: 웹 견적서 뷰어

- URL: `/invoice/[id]` 형태의 공개 링크
- 견적서 항목 테이블 (품목, 수량, 단가, 금액)
- 소계 / 세금(VAT 10%) / 합계 자동 계산
- 회사 로고 및 브랜드 정보 표시
- 인쇄/화면 최적화 레이아웃

### 기능 3: PDF 다운로드

- 브라우저 내 "PDF 저장" 버튼 클릭 시 다운로드
- 파일명: `견적서_[견적번호]_[클라이언트명].pdf`
- 인쇄용 CSS 적용 (불필요한 UI 요소 제거)

### 기능 4: 견적서 목록 (관리자용)

- URL: `/admin/invoices`
- 간단한 패스워드 보호 (환경변수 기반)
- 전체 견적서 목록 조회 및 링크 복사 기능

### 문서 구조

```
1. 프로젝트 개요
   - 배경 및 목적
   - 목표 사용자 (페르소나)
   - 성공 지표 (KPI)

2. 기능 명세
   - 기능별 사용자 스토리 (User Story)
   - 수용 기준 (Acceptance Criteria)
   - 우선순위 (P0/P1/P2)

3. 기술 아키텍처
   - 시스템 구성도 (텍스트 다이어그램)
   - 폴더 구조
   - API 설계 (Route Handlers)
   - 노션 데이터베이스 스키마

4. UI/UX 요구사항
   - 페이지별 와이어프레임 (텍스트 기반)
   - 반응형 브레이크포인트
   - 견적서 레이아웃 스펙

5. 개발 로드맵
   - Phase 1: 기반 구축 (1주)
   - Phase 2: 핵심 기능 (1주)
   - Phase 3: 마무리 및 배포 (1주)
   - 각 Phase별 태스크 체크리스트

6. 비기능 요구사항
   - 성능 (LCP, FID 목표)
   - 보안 (노션 API 키 보호)
   - 접근성 (WCAG 2.1 AA)

7. 리스크 및 제약사항
```

### 추가 지시사항

- 모든 내용은 **한국어**로 작성
- 코드 예시는 실제 구현 가능한 수준으로 작성
- 견적서 UI는 A4 비율(210mm × 297mm)을 기준으로 설계
- 노션 API v1 기준으로 작성
- 환경변수 목록 포함 (`NOTION_API_KEY`, `NOTION_DATABASE_ID`, `ADMIN_PASSWORD`)

작성 후 `docs/PRD.md` 경로에 저장하고, 주요 섹션 요약을 채팅창에 출력해주세요.
